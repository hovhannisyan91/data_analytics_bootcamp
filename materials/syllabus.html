Schedule & Topics

Statistics and Analytical Thinking

Duration: 4 weeks

Goal: Build the statistical vocabulary and reasoning needed to describe data, understand uncertainty, identify bias, sample responsibly, and evaluate evidence with hypothesis tests.

Week 1: Analytics Foundations and Descriptive Statistics

  • What data analytics is and how businesses use it
  • Descriptive, predictive, and prescriptive analytics
  • Data lifecycle and professional roles
  • Zero-, first-, second-, and third-party data
  • Insights, reporting, storytelling, and single source of truth
  • Data coverage, collection, measurement, analysis, and reporting biases
  • Categorical and numerical data
  • Mean, median, mode, frequency distributions, and distribution shape
  • Range, variance, standard deviation, coefficient of variation, z-scores, percentiles, and measures of association

Week 2: Probability Distributions

  • Random variables, probability functions, expected value, and variance
  • Continuous probability distributions
  • Normal, standard normal, uniform, and exponential distributions
  • Discrete probability distributions
  • Poisson and Bernoulli distributions
  • Business interpretation of probability models
  • Central Limit Theorem

Week 3: Sampling and Inferential Statistics

  • Populations, samples, and sampling frames
  • Probability and nonprobability sampling methods
  • Sampling and nonsampling errors
  • Sampling distributions and point estimates
  • Confidence intervals for means and proportions
  • Required sample size
  • Null and alternative hypotheses
  • Test statistics, p-values, and decision rules
  • One-tailed and two-tailed tests
  • Type I and Type II errors
  • Comparing two population means

Data Analytics with SQL

Duration: 7 weeks

Goal: Develop an end-to-end PostgreSQL workflow: design relational structures, clean and query data, construct reusable analytical logic, and deliver a documented SQL project.

Week 1: Relational Databases and PostgreSQL

  • Install and configure Docker, VS Code, Git, and GitHub
  • Structured, semi-structured, and unstructured data
  • Spreadsheets versus relational databases
  • Database types and data management architectures
  • PostgreSQL databases, schemas, and tables
  • Primary keys, foreign keys, and indexes
  • PostgreSQL data types and data dictionaries
  • Create and query a sales analytics database

Week 2: Query Execution, Constraints, and Filtering

  • SQL as a declarative language
  • Query optimization and query plans
  • Refine SELECT statements with aliases and distinct values
  • Choose appropriate data types and constraints
  • Build and index a denormalized analytical table
  • Filter with WHERE and HAVING
  • Combine conditions, ranges, and patterns
  • Create conditional logic with CASE

Week 3: Numeric and String Functions

  • Aggregate with SUM, AVG, COUNT, MIN, and MAX
  • Group analytical results and handle NULL values
  • Perform row-level arithmetic
  • Round and transform numeric values
  • Profile text using length and pattern checks
  • Clean text using trim, case conversion, and replacement
  • Use regular expressions, substrings, concatenation, and related string functions

Week 4: Date Functions, Normalization, and Joins

  • Work with date and timestamp data
  • Use EXTRACT, DATE_PART, and DATE_TRUNC
  • Perform date arithmetic and interval calculations
  • Create date series and control analytical time grains
  • Apply first, second, and third normal forms
  • Decompose tables into a relational schema
  • Define keys and relationships
  • Join normalized tables for analysis

Week 5: Advanced Query Structure and Window Functions

  • Organize intermediate results with temporary tables
  • Use scalar and table subqueries
  • Build readable analytical pipelines with common table expressions
  • Apply aggregate and statistical window functions
  • Compare rows with LAG and LEAD
  • Rank records and calculate running metrics
  • Control partitions, ordering, and window frames

Week 6: Reusable SQL and Advanced Aggregations

  • Create scalar and table-valued user-defined functions
  • Build and execute stored procedures
  • Choose between functions and stored procedures
  • Create analytical views and materialized views
  • Combine results with UNION and UNION ALL
  • Build hierarchical summaries with ROLLUP
  • Build cross-dimensional summaries with CUBE
  • Define targeted summaries with GROUPING SETS

Week 7: Final SQL Project

  • Select a business domain and define analytical questions
  • Design and normalize the data model
  • Create the database, schema, tables, and constraints
  • Load and validate the data
  • Create an ERD and data dictionary
  • Build a denormalized analytical output
  • Visualize results
  • Document the project in GitHub
  • Present the final analysis

Python for Data Analytics

Duration: 8 weeks

Goal: Build reproducible analytical workflows in Python, moving from programming and data wrangling through visualization, experimentation, predictive modeling, segmentation, geospatial analysis, and database integration.

Week 1: Python Foundations

  • Install Miniconda and create a Python environment
  • Configure packages, requirements, notebooks, and VS Code
  • Understand automation, scale, and reproducibility
  • Compare the roles of SQL and Python in analytics
  • Work with variables and core data types
  • Use arithmetic operations
  • Work with lists, tuples, sets, and dictionaries
  • Understand mutable and immutable objects
  • Write conditionals, loops, nested logic, and list comprehensions

Week 2: Data Analysis with pandas

  • Create and work with Series and DataFrames
  • Import and inspect CSV data
  • Select, filter, rename, and transform columns
  • Convert data types and export results
  • Use relative file paths
  • Explore multi-table datasets and data dictionaries
  • Merge DataFrames using different join types
  • Validate merges and investigate unmatched rows
  • Build a denormalized analytical DataFrame

Week 3: Data Visualization and Reusable Functions

  • Match analytical questions to appropriate charts
  • Apply data-ink, clarity, and storytelling principles
  • Identify chartjunk and common visualization mistakes
  • Use the grammar of graphics
  • Build comparison, trend, distribution, and relationship charts with Matplotlib
  • Write reusable functions with parameters and default arguments
  • Create derived analytical columns
  • Use apply, map, vectorized operations, and lambda functions

Week 4: Dates and Interactive Visualization

  • Create, parse, format, and compare Python datetime values
  • Perform date arithmetic
  • Convert and analyze pandas datetime columns
  • Extract calendar features with datetime accessors
  • Filter, sort, and generate date ranges
  • Build interactive charts with Plotly
  • Configure chart templates and colors
  • Highlight important categories and values
  • Add vertical and horizontal reference lines

Week 5: Customer Segmentation and Experimentation

  • Calculate recency, frequency, and monetary measures
  • Create and interpret RFM scores
  • Identify top customers and define customer segments
  • Visualize segment distributions
  • Define A/B test metrics
  • Perform power analysis and determine sample size
  • Create random samples and test hypotheses
  • Distinguish statistical significance from practical significance
  • Use A/A tests, multivariate tests, and multiple-testing corrections

Week 6: Cohort Analysis, Regression, and Forecasting

  • Define cohorts and select retention metrics
  • Prepare cohort periods and cohort sizes
  • Build retention matrices and heatmaps
  • Understand relationships between variables
  • Calculate simple linear regression manually
  • Fit and evaluate regression models with scikit-learn
  • Interpret coefficients and model performance
  • Introduce time-series forecasting with ARIMA and Prophet

Week 7: Classification and Clustering

  • Distinguish regression from classification
  • Model probabilities with logistic regression
  • Interpret odds, coefficients, and decision thresholds
  • Build a customer churn classification model
  • Understand unsupervised customer segmentation
  • Prepare and scale clustering features
  • Apply K-Means and interpret centroids
  • Explore density-based clustering with DBSCAN

Week 8: Geoanalytics and Database Integration

  • Understand latitude, longitude, and spatial data
  • Configure Python geospatial packages
  • Load and analyze Citi Bike data
  • Set up PostgreSQL and PostGIS with Docker
  • Connect Python to PostgreSQL using SQLAlchemy
  • Load analytical data into the database
  • Query and manage spatial data with PostGIS

Tableau

Duration: 4 weeks

Goal: Create clear, interactive, business-ready Tableau dashboards, from data connection and visual foundations through advanced calculations, customer analytics, spatial analysis, and database-backed delivery.

Week 1: Tableau Foundations and Intermediate Visual Analytics

  • Install Tableau Public or Tableau Desktop
  • Navigate the Tableau interface
  • Connect to files and other data sources
  • Work with dimensions, measures, data types, and aggregation
  • Format workbooks and create basic visualizations
  • Add filters and interactivity
  • Publish Tableau workbooks
  • Compare live connections and extracts
  • Use relationships, joins, unions, and data blending
  • Apply Tableau’s order of operations
  • Create calculated fields, parameters, and advanced chart types

Week 2: Advanced Analytics and Dashboard Design

  • Create advanced table calculations
  • Configure partitioning and addressing
  • Use date functions and date parameters
  • Build dynamic time aggregations and KPIs
  • Perform cohort analysis in Tableau
  • Clean and reshape data
  • Apply visual storytelling and color theory
  • Use UX, hierarchy, clarity, and accessibility principles
  • Design dashboard layouts with containers
  • Add dashboard actions and navigation

Week 3: Sales and Customer Dashboards

  • Build KPI cards and sales trend analysis
  • Analyze geographic and product performance
  • Explore sales by weekday and hour
  • Add clustering and returns analysis
  • Assemble a complete sales dashboard
  • Build customer KPIs and growth trends
  • Analyze customer segmentation, revenue, and purchase frequency
  • Create RFM, retention, and behavioral analyses
  • Add dashboard actions and organize container structure

Week 4: Tableau with SQL

  • Connect Tableau to PostgreSQL
  • Prepare views and materialized views for dashboards
  • Validate data quality and row counts
  • Refresh materialized views
  • Prepare database data with SQLAlchemy
  • Design a Citi Bike spatial dashboard
  • Plan the dashboard layout and wireframe
  • Create Tableau calculations and interactions
  • Optimize the dashboard building workflow

Capstone

Duration: 2 weeks

Goal: Build and present an end-to-end data analytics project integrating data modeling, SQL, Python, and Tableau.

Week 1: Project Definition and Data Foundation

  • Define the business problem, objectives, and analytical questions
  • Select and assess the required data sources
  • Design the data model, ERD, tables, and relationships
  • Extract, clean, and transform the data with Python
  • Load and validate the analytical data in PostgreSQL
  • Build reusable SQL queries and summary tables

Week 2: Analysis, Dashboard, and Presentation

  • Explore the data and develop analytical insights in Python
  • Apply an appropriate statistical or predictive method
  • Prepare and validate the final dataset for visualization
  • Build an interactive Tableau dashboard
  • Create a clear visual narrative and business recommendations
  • Organize the code, documentation, and project repository
  • Present the final project and respond to questions
